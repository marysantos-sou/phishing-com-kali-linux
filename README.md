# phishing-com-kali-linux

 Desafio de Engenharia Social com SET - DIO

Nesse projeto foi utilizado a ferramenta setoolkit para criar uma pagina falsa do Facebook para captura de senhas com objetivo de segurança defensiva ..

# Ambiente
- VirtualBox
- Kali Linux
- Social-Engineer Toolkit (SET)

# Objetivo Educacional
Entender, em ambiente de laboratório, como funcionam ataques de engenharia social do tipo Credential Harvester para aprender a se defender.

# O que foi analisado
- Funcionamento do menu Social-Engineering Attacks
- Vetor de Website Attack
- Conceito de Site Cloner usado em simulações de phishing
- Como diferenciar um site legítimo de um site clonado

# Defesas aprendidas
- Sempre verificar o domínio correto (ex: facebook.com)
- Desconfiar de links recebidos por e-mail/mensagem
- Usar autenticação de dois fatores (2FA)
- Treinamento de conscientização para usuários

#Aviso Ético: Este desafio foi executado apenas no ambiente virtual da DIO para fins de estudo. Não utilize essas técnicas fora de um ambiente controlado e autorizado.


# PASSO A PASSO DE COMO FOI REALIZADO ESSE DESAFIO:

O projeto: 

Utilizar a ferramenta o setoolkit para criar uma página falsa do Facebook para capturas de senhas com o objetivo de prevenir de ataques maliciosos.

Para realizar esse desafio do projeto usei a caixa virtualBox, usando o sistema operacional do Kali Linux. 

Após acessar a página de comando do  Kali, digitei o comando: sudo su, apertei a tecla enter e logo em seguida, apareceu o comando pedindo p/ digitar a senha de acesso do meu Kali. Após digitar a senha, apertei a tecla enter e apareceu o comando p/ digitar digitar o nome: setoolkit, após apertei a tecla enter.

 Apareceu um menu com 6 opções p/ mim escolher uma opção c/ o tipo de ataque que vou usar no desafio desse projeto. Nesse caso, escolhi a opção:  1 social- engeneering attacks. Apertei a tecla enter e apareceu um novo menu com 10 opções, para mim escolher uma, escolhi a opção: 2 website attack vectors, que está conforme o desafio do projeto, em seguida, apertei a tecla enter dá enter, apareceu um novo menu com 7 opções, p/ para eu escolher uma, . escolhi a opção:  3  Credential Harvester Attack Method, depois apertei a tecla enter.

 Apareceu um novo menu com 3 opções para mim escolher uma, escolhi a opção: 2 Site Cloner, após escolher a opção, apertei a tecla enter e apareceu um novo comando pedindo o IP Address (após ele pedir  IP Address, automaticamente ele vai te disponibilizar o número do IP Address, que foram 6 números separado por " .")
Após aparecer o número do IP Address, apertei a tecla enter, apareceu um novo comando pedindo pra  digitar o endereço que você quer clonar. Nesse caso, o endereço que eu vou anexar aqui é esse:  http://.www.facebook.com
 
Que estar conforme o desafio desse projeto da DIO.
